# Photograph-to-camera footage

Keep the photographed home as the reference. Decide exactly what the shot must reveal and which photographs establish that space. Describe one camera path, foreground object, final composition and bounded travel. Use a wider corroborating angle before asking the model to expose hidden architecture.

Inspect the provider's current media-role support. An exact first-frame mode may accept one image while a multi-reference mode accepts several without preserving the opening frame. Never promise both unless the selected mode actually supports both. When switching modes, record the tradeoff and compare the generated first frame against all source photographs.

Generate one test before building a batch. Save provider, model, job, prompt, inputs, quoted allocation, returned file and source-comparison evidence. Status is `generated_unreviewed` until the actual video is checked. A provider assistant announcing a generation is not a submitted job: verify a job tile or identifier, completion state and downloaded media.

Review all footage for disappearing furniture, invented tables, extra windows, moved doors, shifting ceiling lights, stretched edges and false connections. A smooth camera path alone does not pass. Compare the ending to a real reverse-angle photo when available. Reject a bad segment; preserve the failed take with the reason. A short valid portion may be used only after checking that portion independently.

Separate shot generation from editing. Build a feature reveal with a coordinated visual, spoken and written opening; let the actual rooms fill the frame. Edit around buyer-life moments and sound, not identical durations or repeated title panels. Do not reuse the same eight-second move at half speed merely to satisfy a requested duration.

Record existing access separately for API prepayment, connector credits and web allowances. Use a supported browser file chooser when the authorized web account has an included allowance that the API does not expose. Do not bypass account agreements or quota enforcement. A funding or media gap remains a disclosed production dependency, not a reason to label a slideshow as a finished cinematic film.
