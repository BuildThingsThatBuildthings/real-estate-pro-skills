# Why each rule is a rule

The banned list looks like style policing until you know what each phrase is a proxy for. This
file is the reasoning, so a rule never gets deleted by someone who only saw the phrase.

## The proxy problem

Almost nothing on the banned list names a protected class directly. That is the point: overtly
discriminatory copy died decades ago, and what replaced it is *proxy language* — phrases that
communicate who a place is "for" without saying so. Enforcement, and plaintiff's counsel, read
proxies fluently. So does the public.

**"Safe neighborhood" / "safe area".** Safety claims are the classic racial proxy, and they are
also unverifiable — safe compared to what, measured how, as of when? Never make safety claims.
Give crime-data sources if a buyer asks, and let them read the source.

**School quality ("great schools", "top-rated").** School-quality language is a demographic proxy
with a long enforcement history, and school ratings encode exactly the demographics the Act
protects. Name the district; never grade it.

**"Perfect for X" / "ideal for X".** Any construction that names an ideal occupant implies the
inverse — who it is *not* for. "Perfect for young professionals" excludes by age and family
status in six words.

**Familial status ("family-friendly", "starter family", "empty nester", "bachelor pad", "no
kids").** Familial status is a protected class, full stop. This includes the flattering versions.

**"Up-and-coming" / "transitional" / "traditional neighborhood".** Coded commentary about who is
arriving in, leaving, or "supposed to be in" an area.

**"Walking distance" / "steps from".** An accessibility problem: it presumes the reader walks.
Use objective distance ("0.4 miles", "near").

**Religious references ("christian", "church nearby").** Religion is a protected class; even
naming an amenity this way signals preference. Name the street, not the congregation.

## The promise problem

**"Guaranteed", "will appreciate", "will sell fast", "closing in N days", "worth $X".** Outcome
promises create liability the moment the outcome misses, and valuation claims without a sourced
appraisal border on a licensed act. The honest versions exist: trailing data, with a source.

## The sourcing problem

**Square footage, room counts, year built, HOA/tax figures, percentages.** These are the numbers
buyers sue over. The rule is not "don't state them" — it is "carry a source or a VERIFY marker",
so a human confirms each against a record before it publishes.

## When a rule seems wrong

Sometimes a phrase is legitimate in a narrow context — "adult living" for a verified 55+
community is the canonical example, and the rule text says so. The gate still fires, because the
narrow context needs a human to confirm it. A gate that guesses about exemptions is a gate that
gets talked out of things.
