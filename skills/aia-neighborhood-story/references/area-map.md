# Area overview with standard editing tools

Use `scripts/render_area_map.py` through the AIA workflow runner for a short geographic insert. It uses the installed Pillow and FFmpeg tools, verified latitude/longitude pairs, the client's existing font and colors, and no map subscription or generation service. Author separate horizontal and vertical configurations. The scene labels itself as a geographic overview, not a route map. Do not infer roads, access points, drive times or walkability from the point locations.

The private config requires width, height, seconds, title, subtitle, font, osm_source, output, attribution and locations. Every location contains label, latitude, longitude, source_url and verified_at. Keep point labels short enough to fit the chosen frame. Use an acquired OpenStreetMap XML source with its license and attribution to draw actual roads and park areas. No client place name is hardcoded in the renderer. A still_output PNG provides a companion graphic; declare it as an output. Bind the config, map source and font as actual workflow inputs, with the authoring producer identity for the config. Output is a silent MP4 for the narrated neighborhood edit; it is not standalone captured neighborhood footage. Inspect marker placement, labels, north orientation and geography against the source before using it. Keep the source records and rendering receipt private.
