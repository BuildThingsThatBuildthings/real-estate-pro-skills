# The conversation

The reconciliation is a document, but the document is not the point. The point is
the ten minutes where a client has a printout from an assistant and the agent has
a file, and only one of them is going to feel defensive.

## The failure this skill exists to prevent

The reflex is to correct. Show more comps, re-explain the pricing, push back on
what the client read. It loses, reliably, for a structural reason: **once it
becomes the agent versus the algorithm, the agent has already lost ground.** The
assistant looks neutral and reads as confident. The agent looks like an
interested party defending a commission.

You cannot win that frame. You can decline to enter it.

## What replaces it

Do not compete on the answer. Compete on **how the decision gets made**. An agent
who explains what a model can see, what it cannot, and which of the two this
decision turns on has given the client something the chatbot cannot supply — and
has done it without telling anyone they were wrong.

That is why the gate refuses adversarial framing outright. It is not politeness
policing. Every blocked phrase is a way of entering a frame that does not pay.

## Order

Sequence carries more weight than content here.

1. **Credit the work.** They researched their own transaction. That is good, and
   an agent who is annoyed by it will be replaced by one who is not.
2. **Agreement first.** Everything classed `verified`. This is not softening —
   it is what earns the right to the rest. An agent who leads with the
   disagreement is read as defending a number.
3. **What has moved.** The `stale` claims. Nobody was wrong, the data aged. This
   is the cheapest thing for a client to accept and the natural bridge.
4. **What it could not see.** The `unknowable` claims. This is the section that
   does the actual work, because it reframes the whole exchange from *who is
   right* to *what this kind of tool can and cannot know*.
5. **Where the files differ.** Only now, the `contradicted` claims, each with the
   record behind it.
6. **Not my lane.** The `out_of_scope` claims, routed out.
7. **The next concrete step.** Something physical and dated. Walk the house.
   Sit with the six comps.

Steps 2 through 4 are why step 5 lands. Reordering them is the most common way
this goes wrong.

## Language that fails the gate, and why

| Blocked | Why |
| --- | --- |
| "Actually, …" | The tell that a correction is coming. Clients hear it before the sentence finishes. |
| "You're wrong" / "That's incorrect" | Makes the client defend a position instead of examining it. |
| "ChatGPT is wrong about this market" | Enters the agent-versus-algorithm frame directly. |
| "AI is unreliable" / "Don't trust it" | Attacks a tool the client chose. They will defend it, and now they are arguing for the number. |
| "Trust me" | Asks for belief where a source was available. If a source exists, show it; if not, say so. |
| "I've been doing this for 20 years" | Credentials are not evidence. The assistant has no credentials and made a checkable claim. |
| "With all due respect" / "No offense" | Both are heard as the opening of an argument. |
| "Let me correct that" | Names the conversation a correction, which is the frame to avoid. |

## Two things worth saying out loud

**Do not pretend to more certainty than the file supports.** A range is a range.
An agent who replaces a confident wrong number with a confident wrong number of
their own has taught the client nothing and set up the next argument.

**A disagreement does not have to resolve in the room.** "That is worth sitting
with" is an available ending. The document exists so the client can re-read it
without an agent present, which is when most of them actually change their mind.

## What this is not

Not a rebuttal document. Not a listing presentation. Not a valuation or an
appraisal, and it must never be described as one. It is a written account of what
was checked, against what, and what remains genuinely open.
