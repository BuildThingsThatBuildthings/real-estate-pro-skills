# Cedar House — fictional practice listing

This is invented teaching material. Never publish it as a real listing.

Source: AIA practice fixture v1. Facts: three bedrooms; two bathrooms; covered rear patio; detached garage; separate room currently used as an office. Unknown: price, square footage, school assignment, renovation dates and showing schedule. Desired assets: a concise description and a launch email. Voice: warm, specific, plain English; no exclamation points or hype.

The result should use supplied facts without filling the unknowns. Produce a separate questions list. Do not label the office soundproof or promise privacy. Do not invent a neighborhood, seller name, address or return on investment.
